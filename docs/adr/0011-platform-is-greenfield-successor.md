# The Platform is a greenfield successor, not a reframe of backlog-pilot

This spec is the successor to the running predecessor backlog-pilot (`https://app.glombik26.de` on `87.106.34.240`), written for the empty VPS of this map. The Platform does not inherit that system's object model, Preview naming, Nginx edge, or local registry. The running instance stays that host's PROD; this map does not plan cutover, migration, or shutdown. Reframing the live stack as this Platform was rejected: Feature, Harness, Git path, and Traefik are already different. Calling it only a throwaway pilot was rejected as a label — the live stack is production — but the spec is still unbound by its conventions.

## Considered Options

- **Greenfield successor; no binding conventions; no cutover here** (accepted)
- Throwaway pilot whose conventions are discarded experiments
- The core this spec only reframes
